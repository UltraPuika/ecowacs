# Rollback

**Nothing was modified, so there is nothing to roll back.** This project has not
changed the robot, its firmware, its settings or its voice resources.

If you change the voice in the ECOVACS HOME app (the safe, supported way), you
can return to the previous language in the same place.

A real rollback procedure will exist only together with a real install
procedure (see `INSTALL.md`). Any future procedure is not acceptable unless it
has been **tested** by restoring the original files on the actual robot, and
the original files were backed up before the first change.
